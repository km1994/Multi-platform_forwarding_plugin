主题
图床设置
怎么用？三步即成： ① 选一个图床——推荐 freeimage（免注册、永久有效）；Catbox 风控较激进（可能返回 Invalid uploader）； ② 写正文时「粘贴 / 拖拽图片进正文框」或点上方「🖼 图片」按钮； ③ 图片自动上传并变成 ![](外链) 插入正文，点「测试」可随时验证图床可用性。 上传失败会自动改用其他可用图床（如 catbox 风控返回 Invalid uploader / SSL 失败时），无需手动重试； 若提示全部失败，多为当前网络无法访问境外图床，可注册 ImgBB / SM.MS 填入密钥或配置自定义接口。 注：SM.MS 匿名上传已被官方停用，需免费注册领 Token 才能用。 注：CSDN 等平台会「转存」外链图到自己 CDN，需图床国内可达——推荐 ImgBB / SM.MS，catbox 直链常转存失败。
免注册、无数量限制、单图最大 200MB、链接永久。直链形如 files.catbox.moe/xxx.png。 注意：个别网络环境访问 catbox.moe 会 SSL 失败，此时换 freeimage.host 即可。
免注册即用（内置公共 Key）；如遇公共 Key 失效，到 freeimage.host 免费注册换取专属 Key 填入。
注册后到 api.imgbb.com → Dashboard → API 复制 Key；无数量限制、单图 32MB、永久有效。
sm.ms 免费注册 → Dashboard → API Keys 复制 Token；单图 5MB、每分钟限速。
以 multipart/form-data、字段名 file 发送；保存时会请求该域名的访问权限。
